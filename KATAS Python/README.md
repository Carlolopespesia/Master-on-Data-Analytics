# 🐍 KATAS Python

## 🎯 Propósito del Directorio

Este directorio está dedicado a la práctica intensiva y metódica de la programación en **Python** a través de la metodología **KATAS**.

El objetivo principal de esta sección es:

1.  **Fortalecer la Lógica**: Mejorar la habilidad para descomponer problemas complejos en pasos lógicos y manejables.
2.  **Dominar la Sintaxis**: Afianzar el conocimiento y uso eficiente de las estructuras de datos, funciones y sintaxis fundamental de Python.
3.  **Preparación Analítica**: Servir como base sólida de programación para abordar con mayor fluidez las etapas de Análisis Exploratorio de Datos (EDA) y el Proyecto Final.

---

## 🛠️ Contenido y Metodología

Todos los ejercicios se encuentran en el archivo principal: `KATASmaster.ipynb`.

### Metodología de Práctica

Cada **Kata** aborda un concepto fundamental del lenguaje y se resuelve dentro de un **Jupyter Notebook** para facilitar la documentación y la ejecución del código. Los ejercicios cubren, pero no se limitan a, los siguientes temas:

| Tema Clave | Conceptos Prácticos |
| :--- | :--- |
| **Control de Flujo** | Estructuras `if/else`, bucles `for` y `while`. |
| **Estructuras de Datos** | Manipulación de `listas`, `tuplas`, `diccionarios` y `sets`. |
| **Funciones** | Definición de funciones, paso de argumentos y valores de retorno. |
| **Cadenas de Texto** | Métodos de *string*, formateo y expresiones básicas. |
| **Resolución de Problemas** | Algoritmos básicos como conteo de caracteres, inversión de cadenas y cálculos simples. |

### Ejemplo de Ejercicio Incluido

* **Kata de Descuento en Compra**: Implementación de lógica condicional y manejo de entrada de usuario (`input`) para calcular el precio final de una compra aplicando descuentos.
* **Kata de Conteo de Caracteres**: Ejercicio para contar las ocurrencias de cada carácter en una cadena de texto, utilizando diccionarios para almacenar frecuencias.

## ⚙️ Requisitos de Ejecución

Para ejecutar el cuaderno de Katas, solo se requiere un entorno básico de Python:

* **Python 3.x**
* **Jupyter Notebook** o **JupyterLab** (o cualquier entorno que soporte archivos `.ipynb`).
* No se requieren librerías externas avanzadas (como *Pandas* o *Numpy*), ya que el enfoque es en el *core* de Python.
