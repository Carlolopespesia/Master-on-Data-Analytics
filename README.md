# 📂 Portafolio de Proyectos de Análisis de Datos y Programación

## 🌟 Descripción General del Proyecto

Este repositorio constituye un portafolio de trabajos realizados en el ámbito del **Análisis de Datos** y la **Programación**. El objetivo principal es documentar y presentar las habilidades desarrolladas en el flujo completo de un proyecto de *Data Science*, que incluye el Análisis Exploratorio de Datos (EDA) con diferentes herramientas, la práctica de programación fundamental (KATAS), ejercicios de bases de datos (SQL) y un Proyecto Final completo con un enfoque en el análisis demográfico y socioeconómico.

---

## 🏗️ Estructura del Repositorio

A continuación, se detalla el contenido y el propósito de cada directorio principal:

### 1. `EDA Excel GS`
Contiene el **Análisis Exploratorio de Datos (EDA)** realizado inicialmente utilizando herramientas de hoja de cálculo (Microsoft Excel o Google Sheets). Este directorio documenta el primer acercamiento y la limpieza preliminar de datos antes de la implementación con código.

### 2. `EDA Python`
Dedicado al **Análisis Exploratorio de Datos (EDA)** implementado con el lenguaje de programación **Python** y sus librerías especializadas (como *Pandas*, *Matplotlib* y *Seaborn*).

* **`Cuaderno`**: Incluye los *Jupyter Notebooks* con el código, visualizaciones y el análisis descriptivo detallado.
* **`Datos`**: Almacena los conjuntos de datos originales o tratados que se utilizaron específicamente para este EDA en Python.

### 3. `Ejercicio de SQL`
Carpeta con los scripts y la documentación relacionada con la práctica de **Structured Query Language (SQL)**.

* Incluye los pasos de **configuración del entorno** (por ejemplo, con PostgreSQL), la creación de la base de datos (`ejercicio_master`) y la ejecución de consultas para practicar la sintaxis y manipulación de datos en bases relacionales.

### 4. `KATAS Python`
Colección de ejercicios de programación denominados **Katas**. Estos ejercicios se enfocan en la práctica intensiva de la lógica, la sintaxis y las estructuras fundamentales de **Python** para afianzar las bases del lenguaje.

### 5. `proyecto final`
El proyecto integral y de mayor envergadura del portafolio, enfocado en el análisis de datos censales y métricas socioeconómicas. El objetivo es aplicar las habilidades adquiridas en todo el ciclo del análisis de datos, desde la limpieza hasta la obtención de *insights* accionables.

* **`Datos`**: Archivos de datos originales (RAW Data) del Censo de 2015.
* **`Datos_depurados`**: Contiene los conjuntos de datos limpios, transformados y pre-procesados, listos para ser utilizados en el análisis final (por ejemplo: `Hoja_de_datos_UNO_depurado.csv` y `Hoja_de_datos_DOS_depurado.csv`).
* **`Cuaderno`**:
    * Incluye los *Jupyter Notebooks* del proyecto final, donde se realiza el análisis avanzado, la visualización de resultados y se plantean posibles pasos futuros como el modelado predictivo y la segmentación.
    * **`Datos_Depurados`**: Archivos de datos depurados específicos para la carga en los cuadernos del proyecto final.
